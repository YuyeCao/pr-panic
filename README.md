# PR PANIC｜公关危机夜

一款以娱乐行业舆情危机为背景的互动决策游戏。

你将作为艺人团队的 PR 负责人，在一夜之间连续面对恋情曝光、旧采访被翻出、前任发声、品牌与媒体施压等突发事件。每一次选择都会影响后续局面，并最终生成不同的 PR 决策倾向与可能的危机走向。

## 🎮 在线体验

👉 [点击进入 PR PANIC｜公关危机夜](https://yuyecao.github.io/pr-panic/)

## ✨ 游戏特色

- 4 轮连续升级的娱乐舆情危机
- 根据前序选择动态变化的决策路径
- 舆论温度、掌握信息、信息公开度、商务压力等状态变化
- 不同选择对应不同的 PR 决策倾向与可能的危机局面
- 没有标准答案，每种选择都意味着不同的取舍
